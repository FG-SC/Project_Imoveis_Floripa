### Project Description: Real State Floripa

---

**Real State Floripa** is a comprehensive Python project designed to analyze and visualize the real estate market of Florianópolis (commonly known as Floripa). This project leverages the power of Streamlit to create interactive dashboards that provide valuable insights into the local housing market. Here’s what the project offers:

#### Features:

1. **Interactive Dashboards**: 
   - **User-friendly Interface**: Navigate through various sections seamlessly.
   - **Dynamic Charts and Graphs**: Explore trends and patterns in the real estate market through interactive visualizations.

2. **Map Visualizations**:
   - **Geospatial Analysis**: Visualize the distribution of properties across different neighborhoods in Florianópolis.
   - **Interactive Maps**: Zoom in and out, click on properties to get detailed information, and filter by various criteria such as price, size, and location.

3. **Price Estimates**:
   - **Predictive Modeling**: Get accurate price estimates of houses using advanced machine learning algorithms.
   - **Comparative Analysis**: Compare estimated prices with actual listing prices to identify potential investment opportunities.

4. **Original Ad Links**:
   - **Data Transparency**: Access the original links of the property ads where data was scraped.
   - **Up-to-date Information**: Ensure that you are viewing the most recent and relevant property listings.

5. **Detailed Property Analysis**:
   - **Comprehensive Data**: View detailed information about each property, including size, number of bedrooms and bathrooms, amenities, and more.
   - **Historical Trends**: Analyze historical price trends and market dynamics to make informed decisions.

#### How to Use:

- **Explore the Dashboards**: Navigate through different sections to explore various aspects of the real estate market.
- **Filter and Search**: Use filters to narrow down your search based on specific criteria such as price range, property type, and location.
- **Click on Properties**: Click on property markers on the map to view detailed information and access the original ad links.
- **Analyze Trends**: Use the dynamic charts and graphs to analyze market trends and make data-driven decisions.

#### Technologies Used:

- **Python**: Core programming language for data analysis and web scraping.
- **Streamlit**: Framework for building interactive web applications and dashboards.
- **Pandas**: Data manipulation and analysis.
- **Geopandas**: Geospatial data analysis.
- **Scikit-learn**: Machine learning for price prediction
- **BeautifulSoup**: Web scraping to gather data from real estate websites.

#### Conclusion:

**Real State Floripa** is a powerful tool for anyone interested in the real estate market of Florianópolis. Whether you are a potential buyer, investor, or real estate professional, this project provides you with the insights and tools you need to make informed decisions.

Explore the project and discover the dynamic world of Floripa's real estate market!
